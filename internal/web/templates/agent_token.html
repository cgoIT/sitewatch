actions erlaubt Aufträge von Sitewatch, nur diese Aktionen und nur lokal: z. B. ["site-status", "maintenance-on", "maintenance-off"] (alle Namen: README, Abschnitt „Aufträge“). Leer = der Agent fragt nie nach Aufträgen.

{{end}}

roots legt fest, unter welchen Verzeichnissen der Agent Pfade aus Sitewatch akzeptiert. Optional: composer, php, nginx, mariadb (Programme bleiben bewusst lokal). Angekreuzte Programme zeigen auf die Docker-Wrapper aus dem Paket sitewatch-agent; fehlt eine Zeile, nutzt der Agent das Programm direkt auf dem Host. Start: sitewatch-agent -bootstrap bootstrap.json. Der öffentliche Schlüssel prüft die Signatur der Konfiguration.
